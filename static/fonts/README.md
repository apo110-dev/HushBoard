# Yerel yazı tipleri

Arayüz, ağ bağlantısı olmadan da aynı görünmesi için yazı tiplerini yerelden sunar.

- **Literata Variable** — başlıklar; SIL Open Font License 1.1.
- **IBM Plex Sans Variable** — arayüz metni; SIL Open Font License 1.1.

Bu klasörde yalnız Latin ve Latin Extended WOFF2 alt kümeleri bulunur. Dosyalar Fontsource `5.3.0`
paketlerinden alınmıştır. Lisans metinleri `LITERATA-OFL.txt` ve `IBM-PLEX-SANS-OFL.txt`
dosyalarındadır.
